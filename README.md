# PadChat

Your ClickUp chats in their own window, so you never lose your place in a task to answer a message.

## Download

**[Get the latest version →](https://github.com/Padmission/padchat-releases/releases/latest)**

- **Mac:** download the file ending in `.dmg`, open it, and drag **PadChat** into **Applications**.
- **Windows:** download the file ending in `-setup.exe` and run it.

## First launch

PadChat asks you to connect your ClickUp account. It shows you exactly where to click:
open ClickUp **Settings › Apps**, copy your **API Token**, and paste it in. That's it.

Your token stays in your computer's secure keychain and is only ever sent to ClickUp.

## Updates

PadChat updates itself. When a new version is ready you'll see **Restart** in the bottom-left corner.
